Apuntes Temario 03 · Red P2P
Módulo 03 · Red P2P

Propagación de bloques en la red

Una blockchain distribuida necesita que los bloques producidos puedan compartirse entre múltiples participantes. La red P2P permite difundir esta información y mantener una visión común de la cadena.

Red P2P

¿Por qué hace falta una red?

Objetivo: comprender por qué una blockchain real necesita una red P2P para compartir bloques entre múltiples nodos.

Una cadena de bloques artesanal puede funcionar cuando una sola entidad controla la creación y almacenamiento de todos los bloques.

Una blockchain distribuida funciona de manera diferente: existen múltiples participantes y los bloques producidos deben compartirse entre los nodos.

Los materiales señalan que, para pasar de una blockchain artesanal a una blockchain real, se requiere una red P2P para propagar bloques.

Idea principal La red P2P permite que los diferentes nodos conozcan los nuevos bloques producidos dentro del sistema.
Propagación

Del bloque al resto de la red

Cuando se produce un nuevo bloque, esa información debe difundirse entre los participantes de la red.

Esto permite que los distintos nodos conozcan la existencia del nuevo bloque y puedan actualizar su visión de la cadena.

A diferencia de un sistema centralizado, la información no depende de un único servidor, sino que se distribuye entre los participantes.

Flujo de propagación Nuevo bloque → nodo que lo produce → otros nodos → difusión por la red
Minería + red

Del Proof of Work a la propagación

La minería y la propagación cumplen funciones distintas, pero están relacionadas.

El Proof of Work permite encontrar una solución válida para un bloque.

Después, la red P2P permite que ese bloque sea comunicado al resto de los participantes.

Relación Proof of Work → bloque válido → propagación P2P → otros nodos conocen el bloque
Conflictos

¿Qué ocurre si aparecen dos bloques?

En una red formada por múltiples nodos puede ocurrir que dos participantes produzcan bloques diferentes aproximadamente al mismo tiempo.

Por esta razón, una blockchain real necesita no solamente una red P2P, sino también una regla de resolución de conflictos.

Esta regla permite determinar cómo debe continuar la cadena cuando existen temporalmente versiones diferentes.

Problema distribuido Si dos nodos producen bloques distintos al mismo tiempo, la red necesita reglas que permitan determinar qué cadena debe continuar.
Blockchain distribuida

De una cadena artesanal a una red real

El pipeline artesanal de los materiales contiene funciones hash, firma digital, encadenamiento y sellado de tiempo.

Sin embargo, el documento indica que para convertirse en una blockchain real necesita elementos adicionales:

  1. Un mecanismo de consenso para múltiples nodos.
  2. Una red P2P para propagar los bloques.
  3. Una regla de resolución de conflictos cuando aparecen bloques distintos.
De modelo educativo a red real Encadenamiento + consenso + red P2P + resolución de conflictos
Resumen

Propagación de bloques

  • Una blockchain real tiene múltiples participantes.
  • Los bloques deben compartirse entre los nodos.
  • La red P2P permite propagar esos bloques.
  • La propagación permite que los nodos conozcan el nuevo estado de la cadena.
  • Pueden aparecer temporalmente bloques distintos.
  • Por ello también se necesitan reglas de resolución de conflictos.
Ejercicios

Propagación de bloques en la red

Analiza los siguientes escenarios relacionados con nodos, redes P2P y propagación de bloques.

Ejercicio 1 · Propagación P2P

El nodo A conoce un nuevo bloque. Después comunica su existencia a los nodos B y C. Posteriormente, B lo comparte con D y C lo comparte con E.

Pregunta: ¿qué característica de una red P2P se representa en este ejemplo?

Ver respuesta

Representa la propagación distribuida. La información puede pasar de un nodo a otros nodos sin depender de un único servidor central.

Ejercicio 2 · Minería y propagación

Un minero encuentra una solución válida de Proof of Work para un nuevo bloque.

Pregunta: ¿por qué no es suficiente con que solamente ese minero conozca el bloque?

Ver respuesta

Porque una blockchain distribuida está formada por múltiples participantes.

El nuevo bloque debe propagarse por la red para que otros nodos puedan conocerlo y actualizar su visión de la cadena.

Ejercicio 3 · Dos bloques al mismo tiempo

El nodo A recibe primero el bloque X, mientras que otro grupo de nodos recibe primero un bloque Y diferente.

Ambos bloques fueron producidos aproximadamente al mismo tiempo.

Pregunta: ¿qué problema aparece y qué necesita el sistema para solucionarlo?

Ver respuesta

Aparece temporalmente un conflicto entre versiones de la cadena.

El sistema necesita reglas de consenso y de resolución de conflictos que permitan determinar cómo debe continuar la cadena.

Ejercicio 4 · Ordena el proceso

Ordena los siguientes acontecimientos:

  • Otros nodos conocen el nuevo bloque.
  • Se obtiene una solución válida de Proof of Work.
  • El bloque se propaga por la red P2P.
  • Se produce un nuevo bloque válido.
Ver respuesta
  1. Se obtiene una solución válida de Proof of Work.
  2. Se produce un nuevo bloque válido.
  3. El bloque se propaga por la red P2P.
  4. Otros nodos conocen el nuevo bloque.
Idea general Proof of Work → nuevo bloque → propagación P2P → otros nodos
